## 📖 项目简介

本项目提出一种**颠覆性的分布式地应力监测理论框架**，为地震短期预测提供全新技术路径。

**核心思想：完全摒弃"传感器必须结构完整"的传统范式。** 系统采用牺牲式超细极化探针作为基本传感单元——探针被地应力主动压裂破碎，通过一次性兆伏级高压脉冲对探针及周围地层进行定向极化。**镓铟锡（GaInSn）无毒液态合金**在探针破碎后自动填充裂缝并形成连续导电网络，利用汞/液态金属-岩石界面接触电阻对裂缝宽度的指数敏感性，实现对纳米级地壳微变形的高灵敏度检测。

## 🔬 系统架构

系统由四个集成模块组成：

| 模块 | 功能 |
|------|------|
| **牺牲式极化探针单元** | 四层同轴结构（GaInSn液态合金芯→PZT压电涂层→钨丝增强→聚酰亚胺绝缘），直径1.0 mm，长度100–500 m |
| **瞬时高压极化单元** | Marx发生器产生数兆伏至数十兆伏级脉冲，对探针及周围1–3 m地层定向极化 |
| **界面电阻信号采集单元** | 采集破碎后液态合金-岩石裂缝接触电阻变化，检测0.1 nm量级微变形 |
| **多站联合差分处理中心** | 三站差分算法滤除99.99%外界电磁干扰 |

## ⚙️ 核心创新

### 1. 牺牲式传感范式
探针的破碎过程本身就是地应力集中的直接度量——破碎程度越高，该区域应力越大。液态合金自动渗入裂缝，形成连续三维导电网络，系统对物理破坏具有内在容错性。

### 2. 高压定向极化
强电场强制旋转地层中天然压电矿物（石英、长石）的晶格，使压电极化方向与外场一致，相干信号叠加，**信噪比理论提高1000倍以上**。

### 3. 界面电阻超灵敏调制
破碎后的液态合金-岩石裂缝接触电阻与裂缝宽度满足指数关系：

$$R_c(w) = R_0 \cdot e^{\beta(w - w_0)}$$

其中 $\beta \approx 10^7 \text{ m}^{-1}$。当裂缝宽度变化 $\Delta w = 0.1 \text{ nm}$ 时，相对电阻变化达 0.1%——**灵敏度比传统应变片高至少三个数量级**。

**关键洞察**：0.1 nm 的全部变形集中在**一个界面**上，信号不分散。这是本方案灵敏度超越分布式（逾渗网络）方案的根本物理原因。

### 4. 多站联合差分抗干扰
三站差分算法可滤除 **99.99%** 外界电磁干扰（车辆、雷电、工业用电等）。

### GaInSn 液态合金 vs 液态汞

| 参数 | 液态汞 | **GaInSn (Galinstan)** |
|------|--------|------------------------|
| 熔点 | −39°C | **−19°C** ✅ |
| 电导率 | 1.0×10⁶ S/m | **3.46×10⁶ S/m** ✅ |
| 粘度 (25°C) | 1.5 mPa·s | **2.4 mPa·s** ✅ |
| 表面张力 | 485 mN/m | **535 mN/m** ✅ |
| 毒性 | ⚠️ 剧毒 | ✅ **无毒** |
| 成本 | ~30 USD/kg | ~100–200 USD/kg |
| 岩石润湿性 | 不润湿 | 不润湿 |
| 每探针(500m)芯材成本 | ~15 元 | **~50–100 元** |

### CNT流体为何被否决

详见 [`FEASIBILITY_CNT.md`](./FEASIBILITY_CNT.md) 完整分析。三个致命缺陷：

| # | 缺陷 | 物理原因 |
|---|------|---------|
| 1 | **信号被稀释** | 裂缝宽度（μm）>> CNT-CNT间距（nm），0.1nm变形被稀释至单个隧道结感知<0.01 fm |
| 2 | **无法渗透裂缝** | 导电浓度下CNT分散液呈膏状非牛顿流体，无法渗入微米级裂缝 |
| 3 | **地下水致命** | 开放裂缝中地下水稀释CNT分散液，彻底破坏导电网络 |

### 关键结论

1. **GaInSn 合金是最优导电介质**：无毒、导电率超汞 3 倍、成本仅增 ¥350–1,200/探针
2. **总成本仍降低 99.99%**：GaInSn 成本增加在系统层面几乎不可见
3. **运维成本优势显著**：牺牲式探针无需更换，省去传统方案中 26% 的年运维支出
4. **中国供应链优势**：镓（全球产量 >90% 在中国）、铟（>50%）、锡（>30%）均可在国内采购，不受出口管制影响
