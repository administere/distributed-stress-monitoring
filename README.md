## 📖 项目简介

本项目提出一种**颠覆性的分布式地应力监测理论框架**，为地震短期预测提供全新技术路径。

**核心思想：完全摒弃"传感器必须结构完整"的传统范式。** 系统采用牺牲式超细极化探针作为基本传感单元——探针被地应力主动压裂破碎，通过一次性兆伏级高压脉冲对探针及周围地层进行定向极化，利用液态汞导电层的流动性在探针破碎后仍形成连续导电网络，实现对纳米级地壳微变形的高灵敏度检测。

## 🔬 系统架构

系统由四个集成模块组成：

| 模块 | 功能 |
|------|------|
| **牺牲式极化探针单元** | 四层同轴结构（汞芯→PZT压电涂层→钨丝增强→聚酰亚胺绝缘），直径1.0 mm，长度100–500 m |
| **瞬时高压极化单元** | Marx发生器产生数兆伏至数十兆伏级脉冲，对探针及周围1–3 m地层定向极化 |
| **界面电阻信号采集单元** | 采集破碎后汞‑岩石裂缝接触电阻变化，检测0.1 nm量级微变形 |
| **多站联合差分处理中心** | 三站差分算法滤除99.99%外界电磁干扰 |

## ⚙️ 核心创新

### 1. 牺牲式传感范式
探针的破碎过程本身就是地应力集中的直接度量——破碎程度越高，该区域应力越大。液态汞自动填充裂缝，形成连续三维导电网络，系统对物理破坏具有内在容错性。

### 2. 高压定向极化
强电场强制旋转地层中天然压电矿物（石英、长石）的晶格，使压电极化方向与外场一致，相干信号叠加，**信噪比理论提高1000倍以上**。

### 3. 界面电阻超灵敏调制
破碎后的汞‑岩石裂缝接触电阻与裂缝宽度满足指数关系：

$$R_c(w) = R_0 \cdot e^{\beta(w - w_0)}$$

其中 $\beta \approx 10^7 \text{ m}^{-1}$。当裂缝宽度变化 $\Delta w = 0.1 \text{ nm}$ 时，相对电阻变化达 0.1%——**灵敏度比传统应变片高至少三个数量级**。

### 4. 多站联合差分抗干扰
三站差分算法可滤除 **99.99%** 外界电磁干扰（车辆、雷电、工业用电等）。

## 🔮 应用前景

- **地震短期预测**：实现震前数月至数年的长期前兆监测
- **活动断层带密集组网**：100 km 断层监测网络 1–2 个月建成
- **深部应力反演**：浅层密集监测结合弹性反演推算深层应力
- **前兆模式识别**：结合机器学习从海量监测数据中自动识别地震前兆模式
